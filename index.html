Panduan Lengkap Hosting di GitHub & Setup Google Sheets

1

Buat Google Sheet

Buat Google Sheet baru di Google Drive Anda. Buka menu Ekstensi > Apps Script, paste kode di atas, lalu klik Terapkan / Deploy > Web App Baru (Akses: Siapa saja / Anyone).

2

Upload Ke GitHub

Buat repository baru di GitHub (misal: e-jimpitan-panggungrejo). Simpan berkas HTML ini dengan nama index.html lalu commit & push ke repo tersebut.

3

Aktifkan GitHub Pages

Buka Settings > Pages di repository GitHub. Pilih Branch main dan folder /(root), klik Save. Website aplikasi e-jimpitan Anda langsung online!
