Konfigurasi Google Sheets (Real-time Sync)

Masukkan URL Web App hasil deploy Apps Script Google Sheets Pekon Anda.

Skrip Google Apps Script (Copy Paste ke Google Sheets):

Di Google Sheets Anda, buka menu Ekstensi > Apps Script, hapus kode lama, lalu paste skrip di bawah ini:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.timestamp,
    data.idWarga,
    data.namaWarga,
    data.rt,
    data.nominal,
    data.petugas,
    data.catatan
  ]);
  return ContentService.createTextOutput(JSON.stringify({status: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}

Instal Aplikasi E-JIMPITAN

Petunjuk Android (Google Chrome):
  1. Ketuk ikon titik tiga (⋮) di pojok kanan atas browser Chrome.
  2. Pilih menu "Tambahkan ke Layar Utama" atau "Instal Aplikasi".
  3. Aplikasi akan terpasang di HP seperti aplikasi resmi Play Store.
Petunjuk iPhone / iPad (Safari):
  1. Buka aplikasi menggunakan browser Safari.
  2. Ketuk tombol Bagikan / Share di bagian bawah layar.
  3. Pilih "Tambah ke Layar Utama" (Add to Home Screen).
