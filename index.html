Kenapa Masih Ada Address Bar / Baris URL Chrome?

Chrome Android membutuhkan 2 Syarat Wajib agar address bar hilang sepenuhnya:

  1. Wajib Menggunakan HTTPS: Aplikasi harus di-onlinekan ke hosting seperti Netlify/GitHub Pages (alamat https://...), bukan dibuka langsung dari file HP (file:///...).
  2. Pilih "Instal Aplikasi" (Bukan "Tambahkan Shortcut"): Saat menekan titik tiga (⋮) Chrome, pilih opsi "Instal aplikasi" agar Android membuat paket WebAPK mandiri tanpa baris URL Chrome.

Kode Google Apps Script

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(),
    data.id_transaksi,
    data.id_warga,
    data.nama_warga,
    data.rt,
    data.nominal,
    data.petugas
  ]);
  return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}
